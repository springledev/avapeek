# Privacy

This page is about this website, avapeek.com. The Avapeek app itself is run by whoever hosts it; see [How the encryption works](/security) for what an Avapeek server can and cannot see.

## What this site does not do

- **No cookies.** The site sets none.
- **No analytics or tracking.** There are no counters, pixels or tracking scripts.
- **No third-party requests.** Fonts, scripts and images all come from avapeek.com. Nothing is loaded from other companies.

The only thing stored is your light or dark mode choice, which your browser keeps locally and never sends anywhere.

## Hosting

The site is hosted on [Cloudflare](https://www.cloudflare.com/). Like any web host, Cloudflare processes your IP address and basic request details (such as the page requested and your browser type) to deliver the site and protect it from abuse. Cloudflare handles that data under its [privacy policy](https://www.cloudflare.com/privacypolicy/), which also says how long it is kept.

I have not turned on request logging for the site. Cloudflare's dashboard shows me aggregate traffic statistics, such as the number of requests and which countries they come from, but not individual visitors.

## Links to other sites

Links to GitHub and other sites take you off avapeek.com, and those sites' own privacy policies apply.
